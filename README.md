# CodesStageCosmo

This repository contains the Python scripts developed during my internship at CPT. 

## Contents
- `growth_factor.py`: Numerical calculation of the structure growth factor D(t).
- `geodesic_solver.py`: Implementation of the geodesic equation integrator and the redshift for EDS and LambdaCDM univers(Visualization and comparison between Einstein-de Sitter and ΛCDM models.).
- 'CMB temperature perturbation.py' : Photon Trajectories in the Perturbed Universe.

## Dependencies
- Python 3.x
- NumPy, SciPy, Matplotlib
